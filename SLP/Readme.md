# Single Layer Perceptron (SLP)

This project implements a Single Layer Perceptron for binary classification.

Framework: Python, NumPy


Contents
- Perceptron from scratch
- Training on OR gate dataset
- Training with and without bias
- Decision boundary visualization
- Comparison with sklearn perceptron

Results
The perceptron successfully learns a linear decision boundary separating the two classes. Both biased and unbiased models achieve zero classification error, 
demonstrating that multiple valid separating hyperplanes exist for linearly separable data.
